# BlockParty

Proyecto completo de Nicktoons Block Party: juego original con Ruffle, remake HTML5 multijugador y recursos originales.

- [`blockparty/`](blockparty/README.md): juego Flash original ejecutado con Ruffle. Ejecutar `node blockparty/serve.mjs` desde esta carpeta y abrir `http://localhost:8090/blockparty/index.html`.
- [`nickparty/`](nickparty/README.md): remake React y TypeScript con servidor WebSocket, CPU y 18 minijuegos. Ejecutar `npm ci` y `npm run dev` desde `nickparty/`.
- `content/`: archivos SWF, recursos y traducciones utilizados por el original y como referencia para el remake.
- [`nickparty/REVISION_FIDELIDAD.md`](nickparty/REVISION_FIDELIDAD.md): cambios recientes y diferencias pendientes frente al original.

Las dependencias instaladas, compilaciones, capturas temporales, credenciales y configuración local de despliegue se excluyen del repositorio. Los archivos originales conservan los derechos y licencias de sus respectivos titulares.
